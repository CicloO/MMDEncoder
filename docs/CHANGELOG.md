# 1.2.3

- “音视频提取与合并”改为和视频压制一样的批量队列：可一次加入或拖入多个文件，逐个处理并显示每个文件的状态（完成显示 ✓）；新增“清除已完成”和每个条目的“重新导出”“移除”按钮。合并时拖入的音频自动配给选中的视频，也可逐个选择。
- 提取与合并的输出位置可选“与源文件同目录”（默认）、“源目录下的 Encoded 子文件夹”或自定义文件夹，文件名自动生成、自动编号，不再覆盖。
- 编码工具安装位置可更改：“编码引擎”中可选择其他文件夹（已安装的工具一起移过去）或恢复默认位置，选择记在 `data/tools-location.json`。

# 1.2.2

- “音视频提取与合并”页改为与“视频压制”页一致的布局：左侧素材区支持拖入文件（合并时拖入的音频自动作为替换音轨），右侧处理设置，底部预计结果与开始处理。
- 提取与合并的输出文件名自动生成，位置跟随“视频压制 → 输出”设置，已有文件不覆盖、自动编号；仍可手动更改并一键恢复自动。
- 修正“重新导出”按钮和检查更新在发行版中提示“不支持的操作”的问题（界面调用未加入预加载白名单），并新增测试确保界面调用的操作都已放行。

# 1.2.1

- 平台预设增加软件版本：YouTube 4K、B站 4K、B站 1080P60、抖音 / TikTok 4K 各有“· 硬件”（NVENC CQ）和“· 软件”（x264 medium CRF）两个版本，码率相近；X 1080p 保持硬件平均码率。
- 硬件预设速度由 p7 改为 p4（实测画质与码率几乎相同，4K 下快约 2.4 倍）；X 1080p 为固定码率，保留 p7。
- 默认 CQ 调整为 YouTube 27、B站与抖音 29；抖音竖屏预设改为以长边（高）3840 缩放，横屏预设按宽度缩放。
- 队列中已完成或已取消的条目右侧新增“重新导出”按钮（× 左边）：放回队列，下次开始压制时按当前设置导出，已有文件不覆盖、自动编号。
- 新增检查更新：启动时查询 GitHub Releases，“设置与引擎”中可手动检查并打开下载页；不自动下载或替换程序。
- 编码器检测结果缓存到 `data/engine-cache.json`，工具、显卡或驱动变化时自动重新检测，“重新检测”强制重测；再次启动的检测由约 8.6 秒降到约 0.2 秒。
- 默认白天模式；文件详情转换前 / 后左右并排对比；移除透明通道页与底部提示条重复的说明框；收紧功能页标签下方留白。
- 使用说明合并进 README，发行包附带 README.md；新增 MIT 许可证。
- 发行目录与压缩包改名为 `MMDEncoder`；最新版固定在 `release/MMDEncoder`，打包时旧版自动改名为 `release/MMDEncoder-<版本>`；版本号统一取自 package.json。

# 1.2.0

- 修正 VSR 试编码对自定义输出帧率的核验，正确接受 30fps、30000/1001 等所选帧率；VFG 仍要求保持源帧率。

- 编码引擎改为首次下载安装与后续检查更新；隔离版本、发布校验、暂存激活，离线复用已安装版本。
- 支持 NVEncC 8-bit HEVC Alpha，真实码流能力检测，禁止静默软件回退丢失 Alpha。
- 不兼容提示提供一键修正关联设置，保留 Alpha、帧率、输出目录等未涉及偏好。
- 内置预设替换为提供的五个平台上传配置，保留个人预设。
- 随编码器和码率控制显示 CQ / CRF / QP / 平均码率、速度预设说明。
- 文件详情读取转换前 / 后实际媒体参数。
- 新增音视频提取合并页、仅音频输出与 WAV；防覆盖、取消、错误日志。
- RTX VSR 与 VFG 设置、参数校验、实际试编码与输出尺寸 / 帧率验证。
- 源码整理为标准根目录结构；发行包不包含 FFmpeg / ffprobe / NVEncC。
