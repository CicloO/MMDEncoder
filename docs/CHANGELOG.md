# 1.3.0

- 软件名统一为 MMDEncoder：程序文件改为 `MMDEncoder.exe`，窗口标题和界面里也都写作 MMDEncoder。
- 支持自动更新：“设置与引擎”里点“下载并更新”，下载后核对 SHA-256，再点“重启并完成更新”替换程序文件并自动重新打开；`data` 文件夹保留不动，替换失败自动还原旧版本。不使用 PowerShell。从 1.2.4 升级需要手动下载这一次。
- 更新时，新版里有改动的内置预设直接换成新版，个人预设始终保留；暂时无法读取的个人预设原样保留，不会因保存设置被删掉。
- 视频压制队列、音视频队列和预设管理都可以拖动排序；处理中拖动也会按新顺序继续。预设管理里只能按住左侧的六点图标拖动。
- 编码预设旁新增“保存”按钮：把当前设置直接覆盖到选中的预设（有修改时可用）；原按钮为“另存为预设”。
- 预设管理：内置预设也能改名、用当前设置更新或删除，“恢复内置预设”可一键找回；新增“隐藏 / 显示”按钮，隐藏的预设不出现在下拉框里。
- 内置预设不再按网站区分，改为“默认 4K”“默认 1080p”（各有硬件 CQ 29 / 软件 CRF 21 两个版本，AAC 320 kbps），按长边缩放、自动识别横竖屏；新增两个透明素材预设（源分辨率）：“保留 Alpha · ProRes 4444”（MOV、PCM 音频、量化 8，可直接导入 After Effects）、“分离 Alpha · H.264 MP4”（内置硬件预设的参数，彩色 MP4 加无损 `_alpha` 黑白遮罩）。实测 Windows 版 AE 读不到 HEVC Alpha，所以不提供 HEVC Alpha 预设，需要时可手动选 HEVC · NVEncC 加保留 Alpha。
- “透明通道”页去掉“额外导出 Alpha 黑白遮罩”勾选框，改为下拉框里的“分离 Alpha · 彩色视频 + 黑白遮罩”：彩色视频不含 Alpha，可用任意编码器和封装，另外导出 `_alpha` 遮罩；“保留 Alpha”与当前格式不兼容时，提示条里也提供“改为分离 Alpha（保持当前格式）”。
- 透明区域的“合成到黑色 / 白色背景”改为“合成到绿幕（#00FF00）”，方便后期抠像；旧预设里的黑 / 白背景仍可使用。
- 保留 Alpha 不兼容时的一键修正不再提供“切换至 8-bit NVEncC HEVC Alpha”（Windows 版 AE、Premiere 读不到 HEVC Alpha），改为 ProRes 4444、VP9 和分离 Alpha。
- ProRes 可调“画质 · 量化”（1–64，0 为编码器默认）；切换到 ProRes 或在 ProRes 下切换到保留 Alpha 时默认量化 8，文件约为默认的四分之一。原来的 X 1080p 固定码率预设已去掉。
- 输出分辨率新增“按长边缩放 · 自动识别横竖屏”。
- 内置预设的“· 软件”版本默认隐藏，本机不支持 H.264 NVENC 时自动显示。
- 视频编码器名称里的“软件”改为“CPU”（如 H.264 · CPU），硬件编码器统一写作 H.264。
- 音视频页：AAC / Opus / MP3 可选码率，默认跟随源文件码率（无损源用 320 kbps）；新增 MP3 导出；提取视频与合并可选 MP4（默认）或 MKV，MP4 放不下的编码（如 MMD 输出的 AVI 原始视频、WAV 音频）自动改用 MKV。
- 音视频页的队列和“当前文件”也显示文件参数（视频：分辨率、帧率、编码、大小；音频：编码、采样率、声道、时长）；队列和视频压制一样分页。
- 两个页面的音频信息写得更细：编码、码率、采样率和声道（如“AAC LC · 317 kbps · 48 kHz / 立体声”）；无损音频没有码率时显示“无损”。
- 两个页面的“当前素材 / 当前文件”格式统一：音频行与视频参数行同样的字体和排列，下方都显示文件路径；音视频页底部预计结果与视频压制页一样分三行（结果、参数、保存路径）；队列行在帧率和文件大小之间显示音频码率。
- 视频压制与音视频队列改为每页 10 个。
- 修正音视频页删除拖入的文件后，切换页面再回来文件又出现的问题。
- 音视频页可查看文件详情（转换前 / 后，合并时还显示替换用的音频）；底部预计结果栏和视频压制页一样贴在窗口底边。
- 修正 RTX 增强验证通过后底部仍提示“尚未通过本机验证”的问题。
- 前向分析帧数只在 NVIDIA 硬件编码时可填，前向分析级别只在 NVIDIA HEVC / AV1 时可填，其余情况灰显；H.264 NVENC 不再因前向分析级别报错。

# 1.2.4

- “编码引擎”对话框分为“软件更新”和“编码工具”两节并加分隔线；安装位置与“更改位置 / 恢复默认”放在同一行；编码工具的按钮改名为“检查工具更新”，避免与软件的“检查更新”混淆。状态文字与对应按钮放在同一行，减少留白。

# 1.2.3

- “音视频提取与合并”改为和视频压制一样的批量队列：可一次加入或拖入多个文件，逐个处理并显示每个文件的状态（完成显示 ✓）；新增“清除已完成”和每个条目的“重新导出”“移除”按钮。合并时拖入的音频自动配给选中的视频，也可逐个选择。
- 提取与合并的输出位置可选“与源文件同目录”（默认）、“源目录下的 Encoded 子文件夹”或自定义文件夹，文件名自动生成、自动编号，不再覆盖。
- 编码工具安装位置可更改：“编码引擎”中可选择其他文件夹（已安装的工具一起移过去）或恢复默认位置，选择记在 `data/tools-location.json`。

# 1.2.2

- “音视频提取与合并”页改为与“视频压制”页一致的布局：左侧素材区支持拖入文件（合并时拖入的音频自动作为替换音轨），右侧处理设置，底部预计结果与开始处理。
- 提取与合并的输出文件名自动生成，位置跟随“视频压制 → 输出”设置，已有文件不覆盖、自动编号；仍可手动更改并一键恢复自动。
- 修正“重新导出”按钮和检查更新在发行版中提示“不支持的操作”的问题（界面调用未加入预加载白名单），并新增测试确保界面调用的操作都已放行。

# 1.2.1

- 平台预设增加软件版本：YouTube 4K、B站 4K、B站 1080P60、抖音 / TikTok 4K 各有“· 硬件”（NVENC CQ）和“· 软件”（x264 medium CRF）两个版本，码率相近；X 1080p 保持硬件平均码率。
- 硬件预设速度由 p7 改为 p4（实测画质与码率几乎相同，4K 下快约 2.4 倍）；X 1080p 为固定码率，保留 p7。
- 默认 CQ 调整为 YouTube 27、B站与抖音 29；抖音竖屏预设改为以长边（高）3840 缩放，横屏预设按宽度缩放。
- 队列中已完成或已取消的条目右侧新增“重新导出”按钮（× 左边）：放回队列，下次开始压制时按当前设置导出，已有文件不覆盖、自动编号。
- 新增检查更新：启动时查询 GitHub Releases，“设置与引擎”中可手动检查并打开下载页；不自动下载或替换程序。
- 编码器检测结果缓存到 `data/engine-cache.json`，工具、显卡或驱动变化时自动重新检测，“重新检测”强制重测；再次启动的检测由约 8.6 秒降到约 0.2 秒。
- 默认白天模式；文件详情转换前 / 后左右并排对比；移除透明通道页与底部提示条重复的说明框；收紧功能页标签下方留白。
- 使用说明合并进 README，发行包附带 README.md；新增 MIT 许可证。
- 发行目录与压缩包改名为 `MMDEncoder`；最新版固定在 `release/MMDEncoder`，打包时旧版自动改名为 `release/MMDEncoder-<版本>`；版本号统一取自 package.json。

# 1.2.0

- 修正 VSR 试编码对自定义输出帧率的核验，正确接受 30fps、30000/1001 等所选帧率；VFG 仍要求保持源帧率。

- 编码引擎改为首次下载安装与后续检查更新；隔离版本、发布校验、暂存激活，离线复用已安装版本。
- 支持 NVEncC 8-bit HEVC Alpha，真实码流能力检测，禁止静默软件回退丢失 Alpha。
- 不兼容提示提供一键修正关联设置，保留 Alpha、帧率、输出目录等未涉及偏好。
- 内置预设替换为提供的五个平台上传配置，保留个人预设。
- 随编码器和码率控制显示 CQ / CRF / QP / 平均码率、速度预设说明。
- 文件详情读取转换前 / 后实际媒体参数。
- 新增音视频提取合并页、仅音频输出与 WAV；防覆盖、取消、错误日志。
- RTX VSR 与 VFG 设置、参数校验、实际试编码与输出尺寸 / 帧率验证。
- 源码整理为标准根目录结构；发行包不包含 FFmpeg / ffprobe / NVEncC。
