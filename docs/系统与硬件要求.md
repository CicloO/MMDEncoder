# 系统与硬件要求

以下是**建议配置**，并非每种硬件组合都经过实机验证。某项功能能否使用，以软件“编码引擎”里的检测结果和实际试编码为准。

基础功能（CPU 软件编码、ProRes、无损剪辑、音视频处理）不需要独立显卡；只有选用硬件编码、AI 超分或 RTX 插帧时，才需要对应的显卡、显存和驱动。

## 基础配置

| 项目     | 最低建议                         | 推荐                                     |
| -------- | -------------------------------- | ---------------------------------------- |
| 操作系统 | Windows 10 / 11，64 位           | Windows 11，64 位                        |
| 处理器   | 4 核 x64 处理器                  | 6 核或以上的现代处理器                   |
| 内存     | 8 GB                             | 16 GB 或以上                             |
| 显卡     | 基础功能不需要独立显卡           | 带硬件编码器的 NVIDIA / AMD / Intel 显卡 |
| 显存     | 基础功能无要求                   | 使用显卡功能时 4 GB 或以上，视功能而定   |
| 存储     | 软件、编码工具和输出文件所需空间 | SSD，并按预计成片大小预留空间            |
| 网络     | 首次在线安装编码工具时需要       | 装好后，本地压制可离线进行               |

“最低建议”不是严格的运行下限，配置更低的电脑也可能正常使用部分基础功能。

## 各功能的要求

| 功能                              | 硬件与环境                                                                   |
| --------------------------------- | ---------------------------------------------------------------------------- |
| H.264 / HEVC / AV1 / VP9 软件编码 | 只用 CPU；可用的编码器取决于 FFmpeg 版本                                     |
| ProRes 422 HQ / ProRes 4444       | 只用 CPU，建议性能较强的多核处理器                                           |
| NVIDIA NVENC / NVEncC             | 支持目标格式与参数的 NVIDIA 显卡、相应驱动；NVEncC 编码另需 NVEncC           |
| Intel Quick Sync（QSV）           | 带对应媒体编码能力的 Intel 显卡与驱动                                        |
| AMD AMF                           | 带对应媒体编码能力的 AMD 显卡与驱动                                          |
| ArtCNN AI 超分                    | 支持 Vulkan 的显卡（NVIDIA / AMD / Intel）                                   |
| RTX VSR 超分                      | NVIDIA RTX 显卡与驱动，并使用 NVEncC 编码器                                  |
| RTX VFG 插帧                      | NVIDIA RTX 40 / 50 系列显卡、NVEncC 9.36 或更新版本、NVIDIA VFX 运行库与模型 |
| 无损剪辑、拼接                    | 不需要独立显卡；能否切在指定帧取决于源视频格式                               |
| 音频提取、替换、自动对齐          | 不需要独立显卡                                                               |
| PNG 序列                          | 取决于所选编码器；CPU 编码不需要独立显卡                                     |
| MMD 导出插件                      | 64 位 MikuMikuDance；硬件要求取决于所选导出预设                              |

不同显卡支持的编码格式、位深、色度采样、Alpha 通道和 AI 增强各不相同。**有 NVIDIA 显卡不代表所有 NVENC 或 RTX 功能都能用**；RTX 功能请先在软件里点“验证本机 RTX 设置”。

## 按任务规划

| 任务                     | 建议                                                           |
| ------------------------ | -------------------------------------------------------------- |
| 1080p 常规压制           | 8 GB 内存，4 核或以上 CPU                                      |
| 4K 常规压制              | 16 GB 内存，6 核或以上 CPU                                     |
| 4K ProRes / AV1 软件编码 | 16～32 GB 内存，性能较强的多核 CPU                             |
| 4K AI 超分或 RTX 插帧    | 16～32 GB 内存；显存建议 8 GB 以上，实际随功能、模型和尺寸变化 |
| 8K 或大批量任务          | 32 GB 或以上内存，并预留充足显存与磁盘空间                     |

这些数字只用于规划硬件，不保证特定分辨率、速度或滤镜组合的性能。

## 存储空间与管道处理

FFmpeg → NVEncC 的处理通过管道直接传递画面，不生成完整的无损中间视频，因此能减少磁盘写入和临时空间。

- 下游处理较慢时上游会自动等待，不会把整段视频读进内存；但管道和各工具的缓冲仍会占用一定内存。
- 部分编码、封装、剪辑和恢复流程仍会生成临时文件。复杂任务建议保守预留预计成片大小的 **2～3 倍**空间。
- 管道数据只经过内存，不会额外消耗 SSD 的写入寿命。

## 编码工具与离线使用

MMDEncoder 使用 FFmpeg / ffprobe，NVEncC 为可选。首次使用时在“编码引擎”里在线安装，或从已有的 ZIP / 7z 压缩包安装。这些工具和显卡驱动、运行库可能有各自的系统要求。

装好后，本地压制无需联网；检查更新和下载组件时需要网络。

## 兼容性提示

- 没有 NVIDIA 显卡的电脑，仍可使用 CPU 软件编码、ProRes、音视频处理和无损剪辑。
- 内存较小时，避免同时处理多个高分辨率任务即可，不必为了管道处理加装大容量内存。
- 判断硬件是否兼容，请以软件里的检测和测试编码结果为准，不要只看显卡型号。
