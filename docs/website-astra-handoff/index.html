兼容性与常见问题

常见问题
与使用限制

以下说明支持平台、授权、Alpha 兼容性，以及画面放大和剪辑功能的适用条件。

MMDEncoder 是否免费且开源？

是。MMDEncoder 按 MPL 2.0 开源许可发布，可免费使用。修改或重新分发时，请查阅仓库中的 LICENSE。

是否必须使用 NVIDIA 显卡？

不是。常规转码可使用软件编码或兼容的硬件编码器；ArtCNN 可在支持 Vulkan 的 NVIDIA、AMD 或 Intel 显卡上运行。RTX VSR / 帧生成功能则需要对应的 NVIDIA 硬件和运行环境。

哪些透明格式适合 After Effects？

在 Windows 的 After Effects / Premiere 等后期流程中，优先考虑 ProRes 4444，或导出彩色视频并配套单独的黑白 Alpha 遮罩。VP9、HEVC 的透明通道支持因平台和软件而异。

无损剪辑能否在任意帧切割？

不能一概而论。H.264 / HEVC 的无重编码切点通常受 IDR 帧限制；ProRes、UtVideo 可逐帧切割。符合条件的 H.264 / HEVC 文件可使用智能剪切，但切点附近的部分帧需要重新编码。

支持什么系统？需要管理员权限吗？

支持 Windows 10 / 11 x64。便携版无需传统安装；下载编码工具及为当前用户注册 MMD 插件通常不需要管理员权限。

在哪里下载更新和查看变更记录？

请通过 GitHub Releases 下载发行版本，并在 更新日志 中查看功能变化、问题修复与兼容性说明。
