# 官网优化决策

## 最终方向：在原版版式上精修

比较过两个方向：

1. **编辑台重构**：近白工作面、局部接触印样、出版式宋体标题和结构化轨道，视觉更安静，版式变化较大。
2. **原版精修（最终采用）**：保留原有粗体标题、山野插画、倾斜窗口、浅色功能卡片、蓝色 MMD 专区的视觉气质，优化密度、可读性、动画与窄屏。

用户在实现过程中明确表示更喜欢原版，并要求「用原来的板式上优化」。因此最终交付恢复原版构图，不采用第一种方案；用户最新偏好优先于简报中全面重构的建议。

## 保留与优化

- 保留首屏左右构图、浮动信息块、彩色卡片、交互对比、三步 MMD 导出、非零帧音频说明、安装、FAQ 和大字号片尾。
- 保留浓蓝、近白、浅桃/薄荷/淡紫，但降低背景饱和度和厚重阴影。品牌蓝调整为 `#354de0`，正文辅助色为 `#505b76`。
- 沿用 Bahnschrift、平台中文无衬线与 Cascadia/Consolas 技术字体；日语指定日文字体优先，无在线字体。
- 保留原有隐形网格与轻微错位，收敛卡片旋转和纵向位移，减少章节空转。手机正文提高到 13–14px，并为插画留出空间。
- 按用户后续指示，彻底删除贯穿整页的长胶卷 DOM、CSS、SVG 构建与滚动脚本。章节刻度取消无依据的重复时间码。保留 MMD 音频区示意帧范围。

## 动效

保留首屏窗口轻浮动、格式带运动、章节入场与交互对比。去掉信号条、队列进度、时间轴、星形、太阳等独立常驻循环。剩余动效尊重暂停和 reduced motion，阅读进度通过 requestAnimationFrame 合并更新。正文永远默认可见。

## 内容与交互

保留原有三语言文案与检测逻辑，补齐 Alpha 仅遮罩、RTX VFG 的 RTX 40/50 和运行库要求、NVEncC 边界、智能剪切局部重新编码条件。技术事实依据 README.md。修复存储被阻止时，延迟返回的 IP 结果覆盖手动语言选择的问题。

增加键盘 Tab 漫游、方向键/Home/End 模式切换、菜单 Escape 返回焦点、对比滑块可见焦点、无 JavaScript 导航降级、全局滚动条与 forced-colors 基线。所有装饰箭头继续使用 SVG。

只修改本目录；不改动桌面主程序、根目录设计约定或构建流程。
