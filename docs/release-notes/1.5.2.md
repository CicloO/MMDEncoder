## 更新内容

### 新功能

- **关于**：顶栏设置图标改为“关于”，集中显示版本、检查更新、下载与重启安装、作者和支持链接。
  - 本版的简略更新内容随程序保存，离线也能看；内容超出时在固定高度内滚动。“完整发行说明”打开 GitHub Releases。
  - “编码引擎”窗口只负责编码工具的安装、更新和检测。发现软件新版本时，“关于”图标上会显示提示。
- **音频淡入淡出**：视频压制、音视频提取与合并、无损剪辑都可以选择关闭、0.5、1、2 秒。
  - 开头淡入、结尾淡出，每端最长为音频长度的一半，短音频的两段淡化不会重叠。
  - 无损剪辑只淡化整段成片的首尾，片段之间的接缝不淡化。
  - 复制原音轨时不能淡化；Hi-Res 输出需要淡化时会重新编码。
- **超分补帧**：
  - ArtCNN 可以选择 C4F16（推荐）或 C4F32。实测两者画质几乎相同，C4F32 慢约 30%–40%。
  - 超分补帧页重新排版：分为“放大”“补帧”两组，每个选项只保留一行说明，RTX 本机验证集中在页面底部。

### 优化

- “关于”“编码引擎”“预设管理”“MMD 导出”四个弹窗统一高度，小窗口自动适配；弹窗内容在内部滚动，滚动条不再盖住外侧圆角。
- 编码引擎列表更紧凑；MMD 导出的遮罩和淡入淡出并列显示；超分补帧的说明按所选选项精简。
- MMD 导出的选项优先于预设：切换预设不会再改动遮罩选择。MMDEncoder 和 MMD“詳細設定”里的选择以最后保存的为准。
- MMD 插件的说明同步更新，写明输出位置、设置优先级和首尾淡化。
- 无损剪辑的快捷键改为：↑/↓ 跳到上一个 / 下一个可切位置，←/→ 逐帧（Shift+←/→ 仍可跳到可切位置）；滑块获得焦点时同样适用。
- 未开启智能剪切，或文件无法智能剪切时，拖动、点击滑块会自动吸附到最近的可切位置。

### 修正

- 无损剪辑的可切位置标记与滑块位置对齐；滑块现在能拖到第一帧和最后一帧。

## 安装 / 升级

下载 `MMDEncoder-1.5.2-win-x64.zip`，解压后运行 `MMDEncoder.exe`。

已安装 MMD 导出插件的用户：插件在这一版有更新，请在右上角“MMD 导出”里点“更新插件”，然后重启 MMD。
