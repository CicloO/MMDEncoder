## 更新内容

### 新功能

- **日本語 / English 界面**：在右上角“关于与语言 · Language”中切换，也可以跟随 Windows 显示语言（无法匹配时使用英语）。切换立即生效，不会中断正在进行的任务。
- **MMD 插件同步语言**：插件的“詳細設定”窗口在下次打开时使用同一语言，日语使用日文字体。
- **主题色“霓虹青”**：新的默认配色取自图标的青色，进度条前端带粉色；白天与黑夜都适用。想用原来的蓝色，可在“关于 → 设置 → 主题色”中选“钴蓝”。

### 优化

- 日语界面使用 Yu Gothic UI，英语界面使用 Segoe UI。
- 主题按钮改称“白天 / 黑夜”；顶栏上方留出更多空白。

### 自 1.6.1 以来的其他改进

- **编码工具离线安装**：可从本地 ZIP / 7z 压缩包安装 FFmpeg 等工具，验证通过后启用，失败时保留原工具。
- **Alpha 遮罩编码可选**：无损、显卡有损、x264 有损三种，并显示实际使用的编码方式与回退原因。
- **音频对齐**：可按参考视频帧率输入帧偏移；换入音频后自动匹配（可在“关于 → 设置”关闭）；再次拖入音频即替换选中项，右键可分别取消替换与对齐。
- **MMD 导出**：新增手动音频帧偏移，以及“起点为 1 时自动 +1”开关。
- **NVEncC 管道**：改为 FFmpeg → NVEncC → FFmpeg 直接串联，不再生成中间视频文件。
- **软件更新**：支持只下载程序增量包，校验或安装失败时自动改用完整包或还原原版本。
- 视频音频码率默认 320 kbps；完成的任务显示实际输出文件名；提取音频按参考等长输出时不再拉长视频素材；新图标与字标。

## 安装 / 升级

下载 `MMDEncoder-1.7.0-win-x64.zip`，解压后运行 `MMDEncoder.exe`；也可以在软件的“关于与语言”里直接更新。设置、预设和日志（data 文件夹）保留不动。

插件文字随语言切换，建议在“MMD 导出”中点“更新插件”（先关闭 MMD）。
