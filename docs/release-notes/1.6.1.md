## 更新内容

### 新功能

- **合成到纯色**：透明通道处理可选绿幕、黑、白，也可用取色器或输入 `#RRGGBB` 自选颜色。
- **MMD 直接导出支持 NVEncC**：在 MMD 的 AVI 输出中选 MMDEncoder，即可使用 NVEncC 的 H.264 / HEVC / AV1 预设；支持按当前导出选项同时输出独立 Alpha 遮罩。
- **MMD 导出支持 RTX 超分与补帧**：关闭“分辨率和帧率跟随 MMD”，使用预设中的超分或补帧设置。所需显卡、NVIDIA 运行库及 Alpha 限制与视频压制页相同。
- **插件内编码测试**：在 MMD 的“詳細設定”里直接测试窗口当前显示的预设和选项，查看成功、失败原因与用时。测试不保存选项，点“确定”才保存。

### 优化

- 合成到纯色改用更快的处理方式，开发机（较高端 NVIDIA 显卡、多核 CPU）4K 测试约快 7 倍。
- 批量导入视频时同时读取几个文件，开发机 20 个 4K 视频测试约快 2.8 倍；音视频页也限制同时读取的数量。
- 加入很长的 PNG 序列时，帧号检查完成后即可操作，总大小随后异步统计。
- 长队列的设置与队列操作减少数据传输，长时间压制时日志记录开销更小。
- CPU 编码器同时检测，首次启动及重新检测稍快。
- 音频对齐读取放到独立进程，读取更快、内存更少；关闭窗口或更换音轨时停止旧任务并释放音频缓存。
- 无损剪辑使用二分查找定位切点，同一文件再次加入时共享索引。
- 向不支持硬链接的盘复制成品时改为异步，减少界面停顿。
- 内置预设中“分离 Alpha · H.264 MP4”排在“保留 Alpha · ProRes 4444”之前。

### 修正

- 软件退出或被强行结束时，不再留下对齐用的后台进程。
- MMD 的 NVEncC 导出等待编码与封装全部结束后才开始合成音频，正确清理中间文件。

## 安装 / 升级

下载 `MMDEncoder-1.6.1-win-x64.zip`，解压后运行 `MMDEncoder.exe`。压缩包不含个人设置或编码引擎，首次使用请按提示安装引擎；已安装的引擎可继续使用。

**本版必须更新 MMD 导出插件**：先关闭 MMD，在 MMDEncoder 的“MMD 导出”中点“更新插件”或“安装到 MMD”，完成后再打开 MMD。插件只为当前 Windows 用户注册，不修改 MMD 文件夹。

如需恢复原版，请保留旧版本文件夹与其 `data`。本版按新的导出选项保存格式工作，不读取插件 1.4.1 的旧 `alphaMask` 开关。

## 校验

SHA-256 见同目录 `MMDEncoder-1.6.1-win-x64.zip.sha256`。使用 PowerShell 的 `Get-FileHash` 检查下载文件，结果应与校验文件一致。
