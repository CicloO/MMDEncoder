## 更新内容

### 新功能

- **FFmpeg 内置**：软件自带 FFmpeg（9.0.2），解压即可编码，不用再单独下载编码工具。功能与之前下载的完整版相同（x264 / x265 / SVT-AV1 / VP9 / ProRes / NVENC、ArtCNN、Hi-Res 音频），占用空间从约 665 MB 降到约 231 MB。
- **编码引擎窗口**：只管理 NVEncC（NVIDIA 显卡的 NVEncC 编码器与 RTX VSR / VFG 需要），FFmpeg 显示为“内置”。NVEncC 仍按需下载。

### 优化

- 下载完整包后，以前单独下载的 FFmpeg 会自动删除，释放空间。

## 安装 / 升级

请下载 `MMDEncoder-1.7.4-win-x64.zip` 完整包，解压后运行 `MMDEncoder.exe`。设置、预设和日志（data 文件夹）保留不动。

在“关于与语言”里直接更新只会更新程序本身，不会带上内置的 FFmpeg；已下载的编码工具照常可用，编码引擎窗口会提示下载完整包。
