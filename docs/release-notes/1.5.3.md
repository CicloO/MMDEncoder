## 更新内容

### 新功能

- **视频压制替换音频**：和音视频页的合并一样，点队列里视频旁的 ♪ 为这个视频选择音频文件。
  - 音频按视频时长截取，成片长度不变；淡入淡出也按视频结尾计算。
  - 原本没有音轨的视频（包括 PNG 序列）也能加上音频。
  - 音频编码、码率、Hi-Res 仍按“音频”页的设置；在“当前素材”里点“改回原音轨”即可恢复。

### 优化

- 页面标签改为标题栏下方的标签栏，选中的页面用下划线标出；内容在标签栏下方单独滚动，滚动条不再盖住底部的“预计结果”栏，滚动后标签栏下会出现淡淡的阴影。
- “关于”窗口的更新内容高度随窗口大小伸缩，和其他弹窗一致；窗口很矮时改为整体滚动，不再与“作者与支持”重叠。
- 精简音视频提取与合并、无损剪辑页的说明文字，去掉 Hi-Res 说明里的“尚未实际上传验证”。

## 安装 / 升级

下载 `MMDEncoder-1.5.3-win-x64.zip`，解压后运行 `MMDEncoder.exe`。
