## 更新内容

### 新功能

- **直接复制音频**：视频压制的音频编码新增“直接复制原音频 · 不重新编码”，保留源音频不做任何处理。复制时不能淡入淡出、不能使用 Hi-Res 或替换音频；源音频放不进所选封装（例如 PCM 放进 MP4）时，会提示改用 MKV 或重新编码。
- **跟随系统主题**：右键点击顶栏的白天 / 黑夜按钮，改为跟随 Windows 的应用模式；之后左键点击仍可回到白天或黑夜。
- **标题栏随主题变色**：窗口最上方的标题栏跟随软件的白天 / 黑夜，不再出现深色界面配白色标题栏。

### 优化与修正

- 视频压制与音视频提取的音频列表统一了名称和顺序：有损（AAC、MP3、Opus）、无损（FLAC、PCM / WAV）、直接复制原音频。
- 文件详情中，MP4 文件不再显示为“QuickTime / MOV”。
- 转换前后对比时两栏逐行对齐，一侧没有的项显示“—”；音频流不再显示无意义的位深 0 和帧率 0/0。
- MMD 导出时，若预设选择直接复制音频：MOV / MKV 保持 PCM，MP4 改用 AAC，并记入日志。

## 安装 / 升级

下载 `MMDEncoder-1.7.1-win-x64.zip`，解压后运行 `MMDEncoder.exe`；也可以在软件的“关于与语言”里直接更新。设置、预设和日志（data 文件夹）保留不动。
