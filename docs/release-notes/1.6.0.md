## 更新内容

### 新功能

- **音频对齐**：选一段参考音频，自动找出目标音频与参考相差多少，把目标的起点对齐到参考。
  - 适用于音视频页的提取音频与合并、视频压制的替换音频，以及无损剪辑的“起点偏移”（可点“自动填写”）。合并和替换音频时默认自动对齐，可以关闭。
  - 同一首歌的不同版本（原曲与翻唱、不同编曲）也能对齐；两段音频差别太大、找不到可靠结果时会提示，不会自动套用。
  - 提取音频对齐后可选“截到参考的长度”，不够时补静音。对齐需要重新编码音频，不能与“直接复制音轨”同时使用。
  - 点队列行或设置旁的 对齐 按钮打开对齐窗口：上下两条波形，虚线标出参考 0 秒和目标开头；可试听参考、目标或两者叠加（可左右分声道）；左键拖动目标波形对齐，按 ←/→ 按所选步长微调；右键拖动或拖动下方视图条平移，拖动视图条两端或滚轮缩放；参考音频可以直接拖进窗口。
- **视频单独设置**：在视频压制队列里选中一个视频，打开“单独设置”，右侧的压制设置就只对这个视频生效，每个视频可以各自设置；队列里会标出单独设置的目标编码。关闭“单独设置”即清除这些设置、恢复通用设置。
- **用时与剩余时间**：压制完成后显示用时；压制中进度过 2% 后显示预计剩余时间。
- **打开位置**：压制前打开源文件所在文件夹，压制完成后打开成品所在文件夹。
- **拖入音频**：把音频文件拖到视频压制队列，会配给选中的视频（没有选中时给第一个还没有替换音频的视频），并自动对齐。
- **重复加入同一视频**：同一个视频可以多次加入队列，配合单独设置用不同参数各压一份。

### 优化

- **分离导出 Alpha 更快**：彩色视频和黑白遮罩改为一遍解码同时输出；NVIDIA 显卡支持时，遮罩用无损 NVENC 编码，不支持或失败时自动改用 CPU 重试一次。开发机（较高端 NVIDIA 显卡、多核 CPU）4K 测试从约 10.4 秒降到约 6.1 秒。MMD 导出插件的分离遮罩也用同样的单遍方式。
- **合并时长按视频计算**：视频与独立音频合并时，成片长度等于视频长度；音频较长时截断，较短时补静音（直接复制音轨时无法补静音，音频会提前结束）。

### 修正

- 无损剪辑启动时不再自动带上次选择的替换音频，替换方式也恢复默认。

## 安装 / 升级

下载 `MMDEncoder-1.6.0-win-x64.zip`，解压后运行 `MMDEncoder.exe`。本版 MMD 导出插件未改动，无需更新插件。
