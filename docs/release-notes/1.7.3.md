## 更新内容

### 修正

- **编码工具更新失败（EPERM）**：更新 NVEncC 等编码工具时，刚解压的文件可能被杀毒软件短暂占用，导致报“EPERM, Permission denied …staging-…”并更新失败。现在会稍等后重试，不再因此失败。
- **旧版编码工具不再占用空间**：更新编码工具后，旧版本会自动删除（每份 NVEncC 约 650 MB）；之前更新失败留下的临时文件夹也会一并清理。正在使用的旧版本会保留到下次检查更新时再删。

## 安装 / 升级

下载 `MMDEncoder-1.7.3-win-x64.zip`，解压后运行 `MMDEncoder.exe`；也可以在软件的“关于与语言”里直接更新。设置、预设和日志（data 文件夹）保留不动。升级后在“编码引擎”里点一次“检查工具更新”，即可清理以前留下的旧版编码工具。
