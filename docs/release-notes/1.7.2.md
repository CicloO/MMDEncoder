## 更新内容

### 新功能

- **VSR 倍率自动计算**：VSR 倍率输入框右侧新增两个按钮（悬停可看说明，二选一，再点一次回到手动倍率）。
  - **跟随分辨率**：放大到“画质”页设置的输出尺寸（长边或自定义宽高），每个视频自动算出倍率。
  - **最大**：按编码器上限取最高倍率（H.264 4096×4096，HEVC / AV1 8192×8192），每个视频分别计算。
  - 按钮点亮时输入框不可编辑，显示当前视频算出的倍率。
  - 切换到 VSR（或点“保留 RTX VSR / VFG 并修正关联设置”）时，若“画质”页已设了分辨率，会保留它并自动点亮“跟随分辨率”；使用手动倍率或“最大”时，“画质”页的分辨率固定为保持源分辨率，不再因两页设置冲突报错。
- **复制日志与导出错误报告**：任务日志窗口新增“复制日志”和“导出错误报告”。错误报告是一个文本文件，附带软件版本、Windows、CPU、内存、显卡与驱动、编码工具版本、可用编码器和任务设置，方便反馈问题；报告包含文件路径。
- **更新时可不覆盖预设**：新版改动了你修改过的内置预设时，除了“用新版覆盖”和“保留我的版本”，新增“不覆盖”：继续使用你现有的预设；有多个时可一次“全部不覆盖”。

### 修正

- NVIDIA 硬件编码的输出尺寸超过上限（H.264 4096×4096，HEVC / AV1 8192×8192）时，压制前就会提示，不再在编码中途失败。手动 VSR 倍率超限时，会给出这个视频能用的最高倍率。

## 安装 / 升级

下载 `MMDEncoder-1.7.2-win-x64.zip`，解压后运行 `MMDEncoder.exe`；也可以在软件的“关于与语言”里直接更新。设置、预设和日志（data 文件夹）保留不动。
