> 目标用户：MMD 动画创作者、视频剪辑与后期合成人员，以及具有基础视频编码需求的使用者。  
> 本文件提供网站文案建议，其中 MMD 导出插件的说明已补充非 0 帧起始音频导出条件。技术表述以项目 README 中已说明的能力和限制为准。

## 一、文案定位

MMDEncoder 是一款面向 Windows 的视频编码与后期处理工具，重点服务 MMD 动画从渲染输出到最终交付的工作流程。内容应围绕实际使用场景进行介绍，减少夸张修辞和无法验证的效果承诺。

文案编写遵循以下原则：

- 用清晰、专业的功能术语描述软件：批量编码、画面放大、Alpha 通道、片段裁切、MMD 直接导出等。
- 优先说明操作用途和交付格式，再补充优势，不使用“画质神器”“无损增强”“万能兼容”等不准确表达。
- 区分主程序与 MMD 导出插件支持的功能；针对硬件、编码器和文件格式的限制提供明确提示。
- 讲清楚概念演示与真实效果的区别，避免将图形示意视为处理结果或性能测试。
- 页面标题保持适合大字排版的简洁结构，同时避免牺牲关键信息。

## 二、首屏信息建议

**产品定位**：面向 MMD 创作者的视频编码与后期处理工具。  
**核心信息**：整合批量转码、分辨率与画质处理、Alpha 素材输出、片段剪辑及 MMD 直接导出。  
**主要操作**：下载 Windows 便携版、查看功能、阅读项目文档。  
**基本要求**：Windows 10 / 11 x64；部分功能需要额外编码工具或兼容硬件。

## 六、专业术语与技术准确性

1. **平台与安装**：支持 Windows 10 / 11 x64，提供便携版；首次安装 FFmpeg、NVEncC 等编码组件时需要联网。避免将“免安装”写成“所有功能无需配置”。
2. **编码与容器**：支持 H.264、HEVC、AV1、VP9、ProRes 等编码格式，实际可用组合仍受编码器与容器支持情况限制。
3. **ArtCNN**：使用 Vulkan 加速；处理速度和画面效果随模型、设备、源素材与输出尺寸变化。不要把 ArtCNN 的实测结论套用于 RTX VSR。
4. **RTX VSR / VFG**：需要对应的 NVIDIA 硬件、运行环境和 NVEncC；帧生成还有显卡代际和运行库要求。不能宣称所有 RTX 显卡均可使用插帧。
5. **透明素材**：Windows 后期流程中优先介绍 ProRes 4444 和分离 Alpha 遮罩；VP9 / HEVC 的透明通道兼容性应按系统与目标应用区分。
6. **片段剪辑**：H.264 / HEVC 的无重编码裁切通常受到 IDR 关键帧限制；智能剪切需要满足格式要求，切点附近可能重新编码，不应简单称为全程无损。
7. **MMD 直出插件**：当前仅支持 64 位 MMD，且插件直接导出暂不支持 NVEncC 预设。非零起始帧的音频导出可能依赖已保存的 PMM 工程和 WAV 音轨。
8. **开源授权**：使用 MPL 2.0，不应将免费使用误写为可以无条件修改、分发或忽略许可义务。
9. **概念演示**：首页插画、交互对比区和模拟编码状态均应说明属于功能示意，不代表真实截图、编码输出或性能实测。
